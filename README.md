### 👨‍💻 Sistem Özeti (profile.json)

- 🎓 **Gaziantep Üniversitesi**'nde Elektrik-Elektronik Mühendisliği öğrencisiyim.
- 🧠 **Odak Alanlarım:** Uçta Yapay Zeka (Edge-AI), Bilgisayarlı Görü, Gömülü Sistemler ve Yüksek Performanslı Asenkron API Mimarileri.
- 🚀 **Şu an üzerinde çalışıyorum:** Wearable (Giyilebilir) ECG/EMG donanım tasarımı ve doğrudan mikrodenetleyici (ESP32) üzerinde çalışan TinyML biyometrik sınıflandırma modelleri.
- 🌐 **Topluluk:** Otonom robotik, kuantum hesaplama ve yapay zeka üzerine derinlemesine teknik içerikler ürettiğim **Vexira** platformunun kurucusuyum.
- ⚡ **Araştırma:** Sentinel-2 uydu verilerini işleyerek atmosferik gaz emisyonlarını (Spectra-CH4 TR) analiz eden uzaktan algılama sistemleri kurguluyorum.
